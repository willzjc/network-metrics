How to read the fault domains

This page publishes only aggregated, allowlisted metrics: no IP addresses, MAC addresses, Wi‑Fi names or access points, hostnames or routes. One vantage point cannot prove which operator caused a fault. Correlate these UTC times with Vision's handoff counters, session/BGP events and maintenance.
